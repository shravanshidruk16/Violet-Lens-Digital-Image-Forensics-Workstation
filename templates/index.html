Digital Forensics Methodology & Scientific Foundations

1. Cryptographic File Hashing (SHA-256)

Cryptographic hashing applies a deterministic mathematical algorithm to compute a fixed 256-bit digest directly from the exact binary byte stream of evidence. In forensic chain of custody, the hash proves bit-for-bit file integrity from the moment of ingestion. It identifies the file; it does not independently prove real-world authenticity.

2. File Signature & Header Verification

Operating systems often rely on file extensions (.jpg, .png), which are trivial to alter. Digital forensics inspects initial "magic bytes" (e.g. FF D8 FF for JPEG, 89 50 4E 47 for PNG) to detect extension spoofing and file format discrepancies.

3. EXIF & Metadata Extraction

Exchangeable Image File Format (EXIF) metadata stores camera parameters (Make, Model, Exposure, F-Stop, ISO, Focal Length), capture dates, software processing tags, and geolocation coordinates. Because metadata can be modified or stripped by web services, absence of EXIF does not prove tampering, while presence of editing software indicates modification.

4. Error Level Analysis (ELA)

Error Level Analysis applies a known JPEG recompression pass (Quality 90) against an uncompressed representation of the image and calculates absolute pixel differences, amplified for human review. Regions of an image that have been resaved multiple times or spliced from images with different compression histories often exhibit differing error rates. High-contrast edges naturally exhibit higher error. ELA is an investigative heuristic, not an automated proof of forgery.

5. Radiometric Pixel Distribution & Shannon Entropy

NumPy calculates channel histograms across 256 intensity levels. Shannon entropy measures visual information density and randomness. Dynamic range clipping identifies loss of shadow or highlight detail.

6. Evaluative Framework

Violet Lens strictly rejects fabricated "tampering percentages." Digital forensics requires contextual corroboration between physical evidence (metadata, headers), compression characteristics (ELA), and radiometric properties (histograms).
